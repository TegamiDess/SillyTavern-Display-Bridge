# Display Bridge 0.14.2

Renders supported card UI inside SillyTavern using reviewed adapters and portable profiles. Companion V3 Asset Sprites 0.6.4 supplies declared local images and CHARX import handoff.

Start with the [beginner import guide](../START-HERE.md) for step-by-step card setup.

See the [repository README](../README.md) for installation and [testing guide](../TESTING.md) for checks and bug reports.

- [LLM profile-editing prompt](LLM-PROFILE-GUIDE.md): preserve the layout and add grouped outfit mappings.
- [Outfits](OUTFITS.md): named groups, character-labelled mappings, default choices and collapsible editor sections.
- [Bilingual dialogue](BILINGUAL-DIALOGUE.md): bracketed translation first, hover/focus to reveal original speech.
- [Profile format](PROFILES.md) and [JSON schema](profile.schema.json).
- [Scene assembly](SCENE-ASSEMBLY.md), [presentation formats](PRESENTATION-FORMATS.md), [supported styling](PRESENTATION-STYLES.md).
- [Compatibility](COMPATIBILITY.md), [persistence](PERSISTENCE.md), [replacement recovery](REPLACEMENT-RECOVERY.md).
